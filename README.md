# Pro Camera
Live color-grading camera: presets, exposure/contrast/shadows/highlights, split toning, sharpen, vignette, grain, histogram, grid, timer, hardware ISO/shutter/focus/WB (where supported).

## Web app (GitHub Pages)
Settings > Pages > Source: **GitHub Actions**. Push to `main` and open the Pages URL; on phone use "Add to Home Screen".

## Android APK
Push to `main`, open **Actions > Build Android APK**, download the `pro-camera-apk` artifact and install `app-debug.apk`.
